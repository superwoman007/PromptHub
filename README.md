---

## 🚀 快速开始

### 本地运行

```bash
git clone https://github.com/superwoman007/PromptHub.git
cd PromptHub
./start-all.sh
```

访问 http://localhost:5173 就能看到首页！

---

## 🎯 当前功能

- ✅ **首页** - Trending + 分类导航 + 搜索
- ✅ **提示词浏览** - 按分类、标签浏览
- ✅ **提示词详情** - 内容展示 + 示例 + 评分
- ✅ **用户系统** - GitHub 登录 + 个人中心
- ✅ **收藏功能** - 收藏喜欢的提示词
- ✅ **提示词上传** - 分享你的好提示词
- ✅ **5 星评分** - 给提示词打分
- ✅ **中英文切换** - 一键切换中文/英文界面

## 🛠️ 技术栈

| 层级 | 选型 |
|------|------|
| **前端** | React + TailwindCSS + Vite |
| **后端** | Node.js + Fastify |
| **数据库** | SQLite（开发）/ PostgreSQL（生产）|
| **认证** | GitHub OAuth |
| **部署** | Docker + Nginx |
